# factcheck

教材の動画で事実を間違えると、見た子どもがそのまま覚えてしまう。だから公開前に、言い切っている文を一つずつ確かめる。

## 手順

1. **候補を抜き出す。** 台本・字幕・`build.py` があれば、まず道具で候補を出す。

   ```bash
   python3 claims.py <台本.txt | 字幕.srt | content/shorts/*/build.py>
   ```

   道具は [年号][数字][名前][因果][断定] のタグを付けて抜き出すだけで、正しいかどうかは判定しない。
   抜けがないか自分でも読み、道具が拾わなかった主張も足す。

2. **一つずつ判定する。** それぞれを次の4つのどれかにする。
   - **確か**:教科書や事典に普通に載っている、広く認められた事実。
   - **解釈**:事実ではなく、よく使われる説明やまとめ方。歴史の「ねらい」「理由」はたいていこれ。
     間違いではないが、言い切りすぎていないかを見る(例:「幕府のねらいはお金」→「大名の力をおさえるねらいがあったと考えられている」)。
   - **要確認**:確かめきれなかったもの。
   - **誤り**:確かに間違っているもの。直し方を必ず書く。

3. **確かめ方。** 検索ツール(WebSearch など)が使えるときは、公的な機関・教科書会社・博物館・事典など、
   出どころがはっきりした情報で確かめ、URL を書く。使えないときは最初にそう書き、手持ちの知識だけで判定した行は
   「知識のみ」と書く。**出典を作らない。** 見つからなければ「要確認」のまま残す。

4. **子ども向けの言い換えも見る。** やさしく言い換えたせいで不正確になっていないか
   (例:「お金は全部大名もち」は、行列の費用の話としては合っているが、何の費用かがわかるか)。

## 返すもの

| # | 文 | 判定 | 理由・根拠 | 直し方(必要なときだけ) |
|---|---|---|---|---|

表のあとに、**公開前に必ず直すもの**(誤り)と、**できれば直すもの**(言い切りすぎの解釈など)を分けて1〜3行で書く。
書き方は `CLAUDE.md` に従う。最後の1行は「このまま出す？それとも直す？」。
