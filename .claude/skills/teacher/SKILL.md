# teacher

Teacher YAMA の授業や動画の「中身」を作るスキル。台本にする前の、説明の骨組みを作る。

## 最初に決めること

- **だれに**:学年の指定がなければ小6。指定があればその学年に合わせ、まだ習っていない言葉を使わない。
  使うときは一言で説明する。
- **何を**:単元やテーマ。広すぎるとき(「江戸時代」など)は、1本の動画で扱える大きさに絞る案を2〜3個出して選んでもらう。

## 手順

1. **押さえることを3つまでにする。** その単元で、これだけわかればいいことを3つまで。
   教科書の範囲を超える話は入れない。
2. **順を追って説明する。** 知っていること → 新しいこと、の順に進める。1つの段落に1つのことだけ。
3. **身近なたとえを1つ入れる。** 見る子がふだん経験すること(引っ越し、遠足、おこづかい、テスト、部活など)に結びつける。
   たとえが事実をゆがめていないかを確かめる。
4. **よくある間違いを1つ。** その単元で子どもがつまずきやすいところと、正しい理解を書く。
   「よくある」と言えるのは一般によく知られたものだけにし、調査の数字などは作らない。
5. **確認の問題を2問。** 1問は言葉を答える問題、1問は「なぜ」を説明する問題。答えは最後にまとめる。
6. **事実を確かめる。** 使った年号・人名・数字を、`/factcheck` の手順で確かめてから渡す。

## 返すもの

1. この単元で押さえること(3つまで)
2. 説明(話し言葉で。`CLAUDE.md` に従う)
3. たとえ
4. よくある間違い
5. 確認の問題2問と答え
6. 動画にするなら:冒頭の一言の案を2つ(`/yt-script` に渡すとき用)

最後の1行は「この内容で台本にする？それとも直す？」。
