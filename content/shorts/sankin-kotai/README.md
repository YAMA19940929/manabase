    1年おきに家族と離れて江戸へ。お金もぜんぶ自分持ち。
    それでも大名が参勤交代に従ったのは、「将軍に従います」を行動で見せる決まりだったから。
    でもその行列のおかげで、日本じゅうがつながっていったんだ。

    ・大名は1年ごとに領地と江戸を行ったり来たり
    ・奥さんと子どもは江戸に住みっぱなし
    ・行列の費用はぜんぶ大名もち。そのぶん力をたくわえにくくなった

    #参勤交代 #小6社会 #江戸時代 #社会科 #Shorts

    音声:AivisSpeech(阿井田 茂)

タグ: 参勤交代, 小6 社会, 江戸時代, 徳川家光, 大名, 武家諸法度, 歴史 小学生

## 作り直すとき

    bash tools/voice/aivis_up.sh   # 声(AivisSpeech 阿井田 茂)。Docker が必要
    apt-get install -y fonts-noto-cjk ffmpeg
    python3 build.py   # スライドと音声を作り、MP4 と SRT まで書き出す(途中のファイルは build/ に入る)

台本を変えるときは `build.py` の `SCRIPT` を直す。1行が `(画面, 字幕, 読み上げ用の文)`。
書き方はリポジトリ直下の `CLAUDE.md` に従い、公開前に `/factcheck` と `/critique` を通す。
声は共通部品 `tools/voice/tts.py` が選ぶ(AivisSpeech → VOICEVOX → Open JTalk の順)。
