# AIニュースのまとめ動画(のらぬっこ・毎日)

note のAIニュース記事(ChatGPTの添削とClaudeの校正が済んだもの)を、その日の分まとめて1本の縦長動画にする。
公開先は YouTube の「のらぬっこ」。Teacher YAMA には出さない(教育系の動画だけにするため)。

## 分担(2026-11-23 オーナー指示:ChatGPT と分担する)

| 担当 | やること |
|---|---|
| Claude(1回目) | 材料を選び、台本の初稿を書いて Jetpost の「台本ノート」に置き、ChatGPT に添削を頼む |
| ChatGPT | 台本ノートのチャットで添削する |
| Claude(2回目) | 添削を反映して動画を作り、点検して台本ノートに載せ、オーナーに通知する |
| オーナー | 「のらぬっこ」にアップロードして公開する |

定期タスク「毎晩のAIニュース動画(のらぬっこ)」が毎晩2回(18:41 と 21:41、日本時間)動き、毎回、1回目と2回目の
両方の条件を調べて、当てはまる方を行う。

## 1回目:台本の初稿(Claude)

1. **材料を選ぶ。** Jetpost で、タイトルが「AIニュース記事の下書き」で始まるノートのうち、次の両方を満たす一番新しいもの。
   - Claude の「校正が完了しました」のコメントがある(ChatGPT の添削を反映したあとの版)。
   - 「台本作成済み」のコメントがまだない。
2. **台本(script.json の形。`digest.py` の説明を参照)を書く。**
   - 記事の本文にある事実・数字・固有名詞だけを使う。新しい事実を足さない。記事の「まだ分からないこと」を言い切りにしない。
   - 1本あたり2〜3文。全体で3分以内。
   - 書き方はリポジトリ直下の `CLAUDE.md` に従う(話し言葉、決まり文句なし、まとめで終わらない、素直な感想を1〜2か所)。
     毎日同じ言い回しにならないよう、冒頭の一言と、本と本のつなぎ方を日ごとに変える。
   - 字幕は1行16字・2行まで。読み上げ用の文は、数字・年号・英語の社名・人名をかなにする。
   - Anthropic・Claude が出てくるニュースでは、台本づくりに Claude を使っていることを、動画と説明欄で示す。
   - 株価などのニュースでは、説明欄に「投資の勧誘や助言ではありません」を入れる。
   - 書いたら `digest.py` の字幕チェックだけ通しておく(はみ出しはここで直す)。
3. **台本ノートを作る。** Jetpost に「AIニュース動画の台本 <日付>版(のらぬっこ)」を作る。中身は、
   材料の下書きノートへのリンク、台本の表(番号・字幕・読み上げ)、タイトル・説明欄・タグ、
   そして **script.json の全文(コードブロック)**。2回目はこの全文から作業を再開する。
4. **ChatGPT に頼む。** 台本ノートのチャットで、ChatGPT を mention して次を頼む:
   「記事との食い違い・言い切りすぎ、話し言葉として不自然なところや決まり文句、字幕の読みやすさ、
   タイトル案(2つ)と冒頭の一言の改善案を、台本の行番号つきで、このノートのチャットに書いてください」。
5. 材料の下書きノートに「台本作成済み(Claude、日付):<台本ノートのリンク>」と書く。

## 2回目:動画づくり(Claude)

1. **対象を選ぶ。** 「AIニュース動画の台本」で始まるノートのうち、「動画準備完了」のコメントがまだないもの。
   - ChatGPT の添削コメントがあれば、それを反映する。
   - 添削がないまま、台本ノートを作ってから24時間以上たっていたら、添削なしで進め、そのことを通知に書く。
   - どちらでもなければ、まだ待つ(何もしない)。
2. **添削を反映する。** 指摘を1つずつ検討する。事実の指摘は材料の記事(必要なら出典)で確かめてから採用する。
   採用しなかった指摘は理由を残す。直した script.json で台本ノートを更新する。
3. **動画を作る。**
   ```bash
   bash tools/voice/aivis_up.sh            # 声(AivisSpeech 阿井田 茂)。先に dockerd をバックグラウンドで起動しておく
   python3 tools/ainews/digest.py content/ainews/<日付>/script.json
   ```
4. **点検する。** `python3 .claude/skills/critique/subcheck.py <srt>`、
   `python3 .claude/skills/yt-package/title.py --title "<タイトル>"`。台本の事実が記事と食い違っていないかも読み直す。
5. **渡す。** `upload_media` で MP4 を上げ、台本ノートに動画・アップロードの手順・最終のタイトル/説明欄/タグ
   (それぞれコードブロック)・採用した添削と見送った添削(理由つき)を書き足す。
   形は 2026-11-21版のノート(https://www.jetpost.com/notes/3cahoxrqjx/ai-2026-11-21)にそろえる。
6. **知らせる。** 台本ノートに `add_comment`(notify: true)で「<日付>版のAIニュース動画(○秒)のアップロード準備が
   できました」と書く。ChatGPT にも、台本ノートのチャットで「反映しました(採用・見送りはノートに記載)」と伝える。
   材料の下書きノートに「動画準備完了(Claude、日付):<台本ノートのリンク>」と書く。

## 守ること
- Claude は YouTube にアップロードも公開もしない。note にも投稿しない。アップロードと公開はオーナーがする。
- ノートをオーナー以外に共有しない。MP4 はリポジトリにコミットしない。

## ファイル
- `digest.py` … 台本 JSON から MP4・SRT・`youtube.md` を作る
- `content/ainews/<日付>/script.json` … 台本の例(2026-11-21版)。毎日の台本は Jetpost の台本ノートに置く
